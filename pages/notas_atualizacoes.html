Versão 1.0.0 - Criação inicial

Primeira versão funcional do sistema de ouvidoria escolar digital.

Primeira versão

A versão 1.0.0 marcou a criação inicial do Fala CETI - Amargosa, uma plataforma de ouvidoria escolar digital desenvolvida para permitir que estudantes enviem manifestações, acompanhem o andamento pelo protocolo e recebam respostas da equipe responsável. O projeto foi criado com foco em organização, comunicação escolar, facilidade de uso e registro estruturado das solicitações.

Páginas criadas

  • Página inicial com apresentação da ouvidoria escolar digital.
  • Página para envio de manifestação.
  • Página para acompanhar manifestação por protocolo.
  • Página de login da área administrativa.
  • Painel administrativo para gerenciar manifestações recebidas.

Funcionalidades da página inicial

  • Apresentação do sistema Fala CETI - Amargosa como canal digital da ouvidoria escolar.
  • Botões de acesso rápido para enviar manifestação, acompanhar solicitação e acessar a área administrativa.
  • Interface visual moderna com identidade do CETI Amargosa.
  • Navegação principal entre as páginas do sistema.

Funcionalidades do envio de manifestação

  • Opção para o usuário escolher se deseja se identificar ou enviar de forma não identificada.
  • Campos para nome, matrícula e turma quando a manifestação for identificada.
  • Seleção do tipo de manifestação, como reclamação, sugestão, demanda ou elogio.
  • Campo para assunto e descrição da manifestação.
  • Definição de prioridade da solicitação.
  • Validação dos dados antes do envio.
  • Geração automática de protocolo no formato FALA-CETI-XXXXXX.
  • Registro da manifestação no Firebase/Firestore.
  • Exibição do protocolo para o usuário acompanhar posteriormente.

Funcionalidades de acompanhamento

  • Consulta de manifestação por meio do protocolo recebido.
  • Exibição do status atual da solicitação.
  • Exibição de informações como tipo, assunto, turma, data de criação e atualização.
  • Visualização da resposta enviada pela equipe escolar.
  • Área de mensagens para continuidade da comunicação dentro do protocolo.
  • Possibilidade de o usuário enviar novas mensagens relacionadas à manifestação.

Funcionalidades da área administrativa

  • Login administrativo com Firebase Authentication.
  • Redirecionamento automático para o painel quando o usuário já está autenticado.
  • Painel para listar manifestações recebidas.
  • Busca por protocolo ou assunto.
  • Filtros por status e turma.
  • Visualização dos detalhes de cada manifestação.
  • Atualização do status da solicitação.
  • Registro de resposta administrativa para o solicitante.
  • Campo de observação interna para acompanhamento administrativo.
  • Possibilidade de arquivar manifestações.
  • Resumo com quantidade de manifestações por status.

Tecnologias utilizadas

  • HTML para a estrutura das páginas.
  • CSS para o design, responsividade e identidade visual do sistema.
  • JavaScript modular para a lógica de envio, consulta, autenticação e administração.
  • Firebase/Firestore para armazenamento das manifestações e mensagens.
  • Firebase Authentication para acesso administrativo.

Organização do projeto

  • Separação entre arquivos HTML, CSS e JavaScript.
  • Criação de páginas específicas para cada função do sistema.
  • Uso de arquivos JavaScript separados para envio, acompanhamento e administração.
  • Estrutura pensada para facilitar manutenção, revisão de segurança e futuras melhorias.
Resumo da versão: a versão 1.0.0 criou a base funcional do Fala CETI - Amargosa, permitindo o envio de manifestações, geração de protocolo, acompanhamento pelo usuário, comunicação por mensagens e gerenciamento completo pela área administrativa.

Versão 1.1.0 - Atualização de segurança

Atualização voltada para proteção dos dados, privacidade e controle de acesso.

Segurança

A versão 1.1.0 marcou uma etapa importante de amadurecimento do Fala CETI - Amargosa. Nesta atualização, o foco principal foi reforçar a segurança do Firebase/Firestore, proteger melhor as manifestações enviadas, restringir o acesso administrativo e impedir que dados sensíveis fiquem expostos publicamente.

Melhorias no envio de manifestações

  • Ajuste no envio de manifestações não identificadas.
  • Campos de nome, matrícula e turma agora aparecem apenas quando o usuário escolhe se identificar.
  • Correção para garantir que o protocolo seja exibido mesmo em manifestações não identificadas.
  • Aumento do protocolo para 8 caracteres, melhorando a dificuldade de adivinhação.
  • Manutenção da escolha do grau da manifestação: Baixa, Média e Alta.

Melhorias nas regras do Firebase

  • Substituição das regras abertas do Firestore por regras controladas.
  • Bloqueio da leitura pública de todas as manifestações.
  • Permissão para consulta pública apenas por protocolo específico.
  • Bloqueio de listagem pública da coleção de manifestações.
  • Restrição da listagem completa apenas ao administrador autenticado.
  • Controle dos campos permitidos no envio de uma nova manifestação.
  • Validação do formato do protocolo no padrão FALA-CETI-XXXXXX.

Proteção da área administrativa

  • Permissão de acesso administrativo apenas para conta autorizada.
  • Restrição de atualização de status, resposta e observação interna ao administrador.
  • Bloqueio de alteração indevida das manifestações por usuários comuns.
  • Bloqueio de exclusão de manifestações pelo sistema.

Proteção das mensagens

  • Permissão para envio de mensagens apenas dentro de protocolos existentes.
  • Controle para impedir que usuários comuns enviem mensagens como se fossem administradores.
  • Bloqueio de edição ou exclusão de mensagens depois de enviadas.
  • Limitação do tamanho das mensagens enviadas pelo protocolo.

Privacidade e segurança dos dados

  • Redução do risco de exposição de nome, matrícula, turma e descrição da manifestação.
  • Proteção das respostas administrativas e observações internas.
  • Melhoria na separação entre acesso público por protocolo e acesso administrativo completo.
  • Maior controle sobre quem pode criar, consultar, listar e atualizar dados.
Resumo da atualização: a versão 1.1.0 tornou o Fala CETI - Amargosa mais seguro, protegendo melhor as manifestações, mensagens e dados administrativos. A principal melhoria foi substituir regras abertas por regras específicas no Firebase, permitindo consulta por protocolo e restringindo o gerenciamento completo apenas ao administrador autorizado.

Próximas melhorias planejadas

Em versões futuras, o sistema poderá receber melhorias de segurança, documentação, privacidade e organização, seguindo o mesmo processo de evolução aplicado em outros projetos.

  • Testar continuamente as regras do Firestore após novas alterações no sistema.
  • Criar Termos de Uso e Política de Privacidade para a ouvidoria.
  • Aprimorar a página de Termos de Uso e Política de Privacidade conforme o uso real pela escola.
  • Documentar quais dados são coletados e por qual finalidade.
  • Melhorar o controle de acesso administrativo.
  • Evitar leitura pública de manifestações sensíveis.
  • Criar notas de atualização para futuras versões.
  • Avaliar melhorias de interface e navegação entre as páginas.
